# 视频广告去除工具（Video Ad Cutter）

自动检测视频中的转场/硬切，把视频切成一段段；在界面上预览每一段的
首帧并勾选要**删除**的片段，最后把保留的片段重新拼接成新视频。

适用于「视频开头被附加了一段广告」的场景：广告与主片的分辨率、帧率
可能不同，本工具会以**主体视频（保留片段的最后一段）** 的分辨率/帧率
为准重新编码输出。

## 运行环境

- Windows 10/11
- NVIDIA RTX 2060（6G 显存）+ 驱动 591.74，CUDA 13.1 工具链
- 视频编码默认使用 **NVENC 硬件编码器（h264_nvenc）**，自动走 GPU；
  若环境不支持则回退到 CPU 的 libx264。

> 转场检测基于「逐帧像素差异」的内容分析法（自适应阈值），**无需下载任何
> 模型权重**；GPU 加速体现在最后的编码阶段（NVENC）。因此全程不依赖
> 外部大模型或权重文件。

## 快速开始

1. 双击 `launch_gui.bat` 启动图形界面（会自动激活 `venv` 虚拟环境，
   并把自带的 `ffmpeg` 加入 PATH）。
2. 点击「选择视频」选中文件。
3. 点击「检测转场」，等待切分完成（会扫描整段视频）。
4. 界面会列出每一段：缩略图 + 时间段 + 分辨率，默认全部「保留」。
   取消勾选 = 删除该片段（例如取消开头的广告段）。
5. 目标规格会随勾选实时更新（基于保留片段的最后一段 = 主体视频）。
6. 点击「导出视频」，选择保存位置，等待进度条完成。
7. 完成后可点「打开输出目录」查看结果。

## 命令行（无界面）用法

```bat
venv\Scripts\activate
python merger.py "输入.mp4" "输出.mp4" "10-30,40-60"
```

第三个参数是「保留」的时间区间（秒），逗号分隔；其余部分被删除。

## 项目结构

```
video-ad-cutter/
├─ launch_gui.bat      # 双击启动 GUI
├─ gui.py              # tkinter 界面
├─ detector.py         # 转场/硬切检测（OpenCV 逐帧差异）
├─ previewer.py        # 抽取每段首帧缩略图
├─ merger.py           # 按目标规格切割+拼接（NVENC）+ concat
├─ utils.py            # ffmpeg/ffprobe 定位、元数据探测
├─ requirements.txt
├─ ffmpeg\bin\        # 自带 ffmpeg（含 NVENC）
├─ venv\              # Python 3.13 虚拟环境
└─ output\            # 默认输出与缩略图目录
```

## 处理要点

- **转场检测**：对每帧做灰度下采样（320×180），计算相邻帧平均绝对
  像素差；以「中位数 × 2.5 + 5」作为自适应阈值，超过即判定为新片段
  起点（最小片段长度 8 帧）。广告→主片的画幅突变会被高差异捕获。
- **分辨率/帧率统一（需求 #5）**：保留片段逐段重新编码，统一缩放到
  目标分辨率（letterbox 留边）、统一帧率、统一音频采样率；目标取自
  保留片段的最后一段（主片），因此即便广告段分辨率/帧率不同也不影响。
- **音频**：随视频一同切割与重新拼接（`aresample` 统一采样率）。
- **GPU 编码**：`h264_nvenc` + `-cq 21`，自动落到 RTX 2060；
  失败回退 `libx264 -crf 21`。

## 常见问题

- **编码很慢 / 没用上 GPU**：确认 `ffmpeg\bin\ffmpeg.exe` 存在且
  `ffmpeg -encoders | findstr nvenc` 能看到 `h264_nvenc`。若没有，
  程序会自动用 CPU 编码，速度较慢但功能正常。
- **检测把正片也切得太碎**：可在 `detector.detect_scenes` 调高
  `threshold`（默认 18.0）以减少误切。
- **导出后开头/结尾有黑帧**：属正常重编码边界，可在 GUI 中微调勾选项。

## 仓库说明（源代码托管）

- 本仓库只提交**源代码**。`ffmpeg/`（自带编解码二进制）、`venv/`（Python 虚拟环境）、
  `output/`、`test/` 均已在 `.gitignore` 中排除，不会进入版本库。
- 转场检测默认使用 `detector_ffmpeg.py`（基于 ffmpeg `scdet` 滤镜，速度快、
  无需下载任何模型权重）；`detector.py` 为 OpenCV 逐帧差异的兜底实现。
- 本地运行需自行准备：Python 3.13 虚拟环境（`pip install -r requirements.txt`）
  以及一份含 NVENC 的 `ffmpeg`（置于 `ffmpeg/bin/` 下，或确保在 PATH 中）。
